# 电流环 PI 标定说明

> 针对「电机转动不同角度波形差很多」「怎么标定 PI 才是对的」「有没有自动标定」的集中说明。电机规格见 `docs/MOTOR_8HA0205-10_SPEC.md`。

---

## 1. 为什么转动不同角度波形差很多？

根本原因主要有三块，**和“角度”强相关**，不是 PI 本身随角度变化，而是**观测到的 dq 电流和负载随角度变**。

### 1.1 电角度零点未对齐（最常见）

- **现象**：同一套 PI、同一阶跃指令，在不同机械角下做阶跃，VOFA 上 Id/Iq 跟踪形态差别大（有的过冲大、有的慢、有的像“跑偏”）。
- **原因**：dq 轴是跟着**编码器电角度**算出来的。若 `g_M2_ElecAngleOffset` 未校准或不准，则「编码器 0°」和「电机真实 d 轴」有固定偏差 → Park 用的角度错了 → 同一相电流在不同机械角下被分解到 d/q 的比例不同 → 电流环看到的“负载”和耦合程度随角度变，**表现就像波形差很多**。
- **建议**：
  1. 先做 **零点校准**（`ZeroCalib_RunBlocking` 或你现有的电气零点对齐流程），把 `g_M2_ElecAngleOffset` 调到正确值。
  2. 再做阶跃测试时，**固定机械角**（例如先对齐到某一位置再上电），或至少在**同一初始角**下对比不同 PI 参数，避免把“角度错”当成“PI 错”。

### 1.2 齿槽/定位转矩（步进电机特有）

- 规格书 8HA0205-10 有 **定位转矩 5 mN·m**，1.8° 步距角对应 50 极对，齿槽周期明显。
- **现象**：不同机械角下，转子受到的齿槽力矩不同，电流环要克服的“扰动”不同 → 同一阶跃下，有的角度容易过冲/振荡，有的角度更平滑。
- **建议**：PI 按**多转几个角度、多看几组阶跃**来评估，不要只在一个角度调。若多数角度满意、个别角度略差，可接受为齿槽引起，不必为个别角度把 PI 调得很保守。

### 1.3 开环/测试条件不一致

- Live Watch 里若 `g_M2_CtrlMode = M2_MODE_OPEN_LOOP`，且 `g_Enc1_SpeedRPM` 与 `g_Enc2_SpeedRPM` 差异很大（例如 -2747 vs -1），说明两编码器或双机测试状态不一致，**角度基准、速度基准都不同**，波形不可比。
- **建议**：阶跃标定 PI 时，用**单电机 M2 + 编码器 2**，闭环（或至少角度来自编码器且 `g_M2_ElecAngleOffset` 已校准），再固定转速/负载条件，这样“不同角度”的对比才有意义。

## 2. 正确的 PI 标定流程（本项目可用）

当前工程已有 **dq 双轴阶跃录制 + VOFA 回放**，可直接用来标定电流环 PI。

### 2.1 推荐步骤

1. **先校准电角度零点**  
   保证 `g_M2_ElecAngleOffset` 正确（零点校准流程跑通后再做下面步骤）。  
   阶跃录制在 **g_StepCapArm_M1/M2=1** 时会先自动 Id 吸 1s 对齐零点，再开始 d/q 阶跃录制。

2. **固定测试条件**  
   - M2 开环或速度环给固定转速（如 0 或低速），避免速度大范围变化。  
   - 机械上尽量固定同一初始角度再做阶跃，便于复现。

3. **用阶跃录制看 d/q 响应**  
   - Live Watch：`g_StepCapTarget_mA = 200`（或你关心的电流），`g_StepCapArm_M1 = 1`（M1）或 `g_StepCapArm_M2 = 1`（M2）。  
   - 流程：Phase0 录 d 轴阶跃 → 回放 → Phase1 录 q 轴阶跃 → 回放 → 暂停（见 `main.c` 533–589 行）。  
   - VOFA 通道：ch0=Id_ref, ch1=Iq_ref, ch2=Id_fbk, ch3=Iq_fbk；ch5=0 表示 d 轴，1 表示 q 轴。

4. **看波形调参**  
   - **目标**：阶跃后反馈（ch2/ch3）尽快跟上参考（ch0/ch1），**无明显过冲或振荡**（本项目注释里倾向一阶无超调）。  
   - **过冲大**：先略减 `PI_M2_KP_NOM`，ki 可按比例略减（保持 ki/kp≈0.205 再微调）。  
   - **响应慢**：略增 kp（注意 ADC 噪声，kp 过大纹波会变大，见 `main.h` 410–411 行注释）。  
   - 修改 `main.c` 中 `PI_M2_KP_NOM` / `PI_M2_KI_NOM` 后重新编译、再录阶跃对比。

5. **多角度抽查**  
   转几个机械角（例如每隔几十度）重复一次阶跃录制，确认多数角度下响应一致、无异常“波形差很多”的个案；若有，先确认是否零点或齿槽导致，再决定是否微调 PI。

### 2.2 理论参考（本项目已在用的关系）

- τ_e = Ls/Rs，极零对消 ki/kp ≈ Rs/(Ls·Fs)，Fs≈17 kHz。  
- 见 `main.h` 173–178 行、`main.c` 83–108 行：当前 M2 按 Ls=5.3 mH 标定 ki/kp=0.205；阶跃实测等效电感更大时，注释中已说明可接受一阶无超调即可。

## 3. 有没有自动标定？

**当前工程里没有实现电流环 PI 的自动标定。** 参数是手设的（`PI_M2_KP_NOM` / `PI_M2_KI_NOM`），通过阶跃录制 + VOFA 人工看波形来调。

**ST MCSDK 电流环自校准方案**（辨识 R/L 后按公式设 Kp、Ki）已整理在 `docs/CURRENT_LOOP_AUTOCALIB_STMCSDK.md`，摘自参考工程 STOPLL_FOC_2205。

若要做“自动标定”，常见思路有（仅作方向参考，不要求实现）：

- **阶跃响应法**：程序自动发 d/q 阶跃，根据录到的 Id/Iq 上升时间、超调量、调节时间，用简单规则或查表给出 kp/ki 建议（仍可沿用现有 `g_StepCapBuf` 与 VOFA 的录制逻辑，只是分析在 PC 或 MCU 上自动化）。  
- **继电器/极限环法**：用带滞环的 bang-bang 控制激发振荡，从振荡周期/幅值反推对象带宽，再算 PI（实现和调试成本较高）。  
- **在线辨识 L/R**：通过小信号注入或阶跃拟合出 L、R，再按极零对消公式算 kp/ki（需要额外辨识代码和滤波）。

**建议**：先用手动流程（零点校准 + 阶跃录制 + 多角度抽查）把 PI 和“不同角度波形差”的原因理顺，再视需求考虑是否加一层简单的“半自动”（例如固定阶跃 + 自动算上升时间/超调，给出建议 kp/ki）。

## 4. VOFA 通道与阶跃流程速查

| VOFA 通道 | 含义 | 阶跃回放时 |
|-----------|------|------------|
| ch0 (I0)  | Id 参考 (mA) | Id_ref |
| ch1 (I1)  | Iq 参考 (mA) | Iq_ref |
| ch2 (I2)  | Id 反馈 (mA) | Id_fbk |
| ch3 (I3)  | Iq 反馈 (mA) | Iq_fbk |
| ch4 (I4)  | **样本序号** (0~127) | 每点 = 1 个控制周期 (≈58.8µs @17kHz)，**阶跃发生在 10** |
| ch5 (I5)  | phase + **发送翻转方波** | 0/1 + 100×翻转 → 方波，**每半周期 = 1 次发送 ≈1ms**，便于在波形上数时间/周期 |

- 启动：Live Watch 设 `g_StepCapTarget_mA`，置 `g_StepCapArm_M1 = 1`（M1）或 `g_StepCapArm_M2 = 1`（M2），会先 Id 吸 1s 再录。  
- 代码位置：阶跃逻辑 `main.c` 534–597 行；ISR 内录制 `stm32g4xx_it.c` 288–317 行。

## 5. 如何从波形/截图评价 PI（方便你截图给我看）

把 VOFA 回放时的截图发给我时，可按下面方式读数和评价，我就能据此给调参建议：

1. **到目标值用了多少控制周期**  
   - 看 **ch4 (I4)**：阶跃发生在 **ch4 = 10**（STEP_CAP_PRE）。  
   - 看 **ch2（d 轴）或 ch3（q 轴）** 何时到达参考的约 **90%**（对应 ch0 或 ch1 的 0.9 倍）。  
   - **周期数** = 达到 90% 时 ch4 的数值 − 10。  
   - 例如 ch4=25 时 ch3 到 90% → 约 **15 个控制周期**（约 0.9ms @17kHz）。

2. **时间刻度（若不用 ch4）**  
   - **ch5 (I5)** 是 0/1 加 100× 发送翻转的方波，每 **半周期 = 1 次发送 ≈ 1ms**。  
   - 从阶跃起点到稳定，数 ch5 方波的半周期个数 ≈ **毫秒数**。

3. **超调**  
   - 看 ch2/ch3 相对 ch0/ch1 的**峰值**：(峰值 − 稳态) / 稳态 ≈ 超调比例。  
   - 无明显超调、略超调、明显振荡都可以在截图上标一下，我据此建议是否减 kp/ki。

4. **你发截图时最好说明**  
   - 当前是 d 轴还是 q 轴（看 ch5 基线是 0 还是 1）；  
   - 阶跃目标大概多少 mA（`g_StepCapTarget_mA`）；  
   - 当前 PI：kp/ki 是否还是 80000/16400。  

这样我可以直接根据波形和周期数给出「加/减 kp/ki、大致改多少」的具体建议。
